# Code of Conduct

Be kind and be useful. This project is for learning and building together.

- Treat everyone with respect. No harassment, insults, or discrimination.
- Disagree with ideas, not people. Assume good faith.
- Keep feedback specific and actionable; keep criticism about the work.
- Do not publish other people's private information.

Maintainers may edit or remove comments, commits and issues that break these rules, and may block
repeat offenders. To report a problem, use GitHub's private "Report content" option on the
comment, or open a private security advisory as described in [SECURITY.md](SECURITY.md) and say it
is a conduct report.
